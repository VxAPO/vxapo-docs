# VxAPO Documentation

This repository contains the documentation for VxAPO, organized by topic.

## Structure

- `app/` — App reference and UI design
- `cli/` — CLI reference
- `driver/` — Driver architecture, module specification, configuration/DSP design, installation/troubleshooting
- `overview/` — Project overview
- `changelog.md` — Changelog
- `archive/` — Archived documentation removed from source repositories

## Languages

Each topic directory contains `zh/` and `en/` versions.
