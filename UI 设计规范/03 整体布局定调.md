## 一、页面骨架（五区）

```
┌────────────────────────────────────────────────────────────────┐
│ 顶栏：LOGO 设置 保存 导入 导出 ｜ 视图滑块(预设|高级) ｜ ─ □ × │
├──────────┬─────────────────────────────────────────────────────┤
│ 侧边栏   │ 内容块：设备标签页  [设备A] [设备B] [+]             │
│ 预设     │ ┌───────────────────────────────────────────────┐   │
│ 自定义   │ │ 上部：卡片列（预设/高级按视图变化）           │   │
│ 高级 *   │ ├───────────────────────────────────────────────┤   │
│          │ │ 下部：EQ 曲线（始终可见）                     │   │
│          │ └───────────────────────────────────────────────┘   │
├──────────┴─────────────────────────────────────────────────────┤
│ 下边栏：语言 主题 全局调音 ｜ 当前活跃设备信息                  │
└────────────────────────────────────────────────────────────────┘

* 高级栏头仅在高级视图显示。
```

- **顶栏**：全局操作 + 视图切换 + 窗口控件。
- **侧边栏**：预设库 / 自定义预设 / 高级添加源（随视图变化）。
- **内容块**：设备标签页体系 + 卡片列 + EQ 曲线（按设备、按视图变化）。
- **下边栏**：软件状态快捷项 + 当前设备信息。

## 二、顶栏

从左到右固定顺序：

| 序号 | 项 | 说明 |
|---|---|---|
| 1 | LOGO | 品牌标识（品牌青 `#33CCCC` / `#009AA2`） |
| 2 | 设置 | 打开应用设置面板（语言 / 主题 / 更新 / 关于等） |
| 3 | 保存 | 保存当前设备配置（TOML 写入 + 热重载） |
| 4 | 导入 | 导入 TOML（01 双选项：完整 / 仅结构） |
| 5 | 导出 | 导出当前配置 TOML |
| 6 | 视图切换滑块 | 预设 ｜ 高级，作用于**当前激活设备标签页** |
| 7–9 | 最小化 / 最大化·还原 / 关闭 | Tauri 无边框窗口控件 |

- 形状遵循 02：按钮/滑块/窗口控件 = 胶囊。
- **通道选择器已开启的设备，其视图滑块禁用“预设”侧**（该设备锁定高级视图）。

## 三、左侧边栏

**栏头 = 下划线分段切换器**（`预设 ｜ 自定义 ｜ 高级` 一行灰字，选中字变黑、
下方灰条对应段变黑，点击左右滑动动画）；下方卡片 / 列表按列排布。
高级栏头仅高级视图显示。

- **预设**：内置预设卡片——预设名 + 简介 + 添加按钮（胶囊）。
  - 粒度 = **group 整组**（含若干 name 小卡），点击添加整组，删除按整组（01 语义）。
- **自定义**：用户自定义预设卡片——同预设卡片，右上角多一个关闭标志（删除确认）。
- **高级**（仅高级视图显示，切到高级视图时自动出现）：列表式，hover 浮现
  **圆形加号**（圆形底色加号标识，02 组件词汇补充项）。
  - `通道选择器`：单独一项，**添加 = 开启分栏（on）**；开启后卡片列顶部出现
    通道选择栏头。
  - `滤波器`：peak（可用）；高架 / 低架 / 低通 / 高通（置灰占位，未实现）。
  - `效果器`：wide / aural / reverb / maximizer / loudness（driver 全部类型，可添加）。
  - `通道`：列出声道项，hover 圆形加号添加声道。

## 四、内容块（设备标签页体系）

- 只有**已安装设备**出现固定标签页；标签页栏 `+` 打开**新设备安装页面**：
  - 列举当前在线设备：设备类型、设备名、安装状态，以播放 / 捕获区分；
  - 勾选 / 取消勾选执行安装 / 卸载，并显示安装 / 卸载过程进度。
- 已安装设备标签页两个标记：
  - 左侧标记 = 该设备**调音开关**（启用 / 关闭调音）；
  - 右侧标记 = 关闭标签页（**卸载设备**，弹确认窗口）。
- **活跃 / 非活跃区分**：活跃标签 = **反圆角标签页**（`clip-path: shape(...)`，
  背景 = 页面底色），标签头与调音卡片、频响曲线**同一颜色页面**，体现设备与
  调音一体感；活跃标签**整体右移**，底部反圆角衔接到内容矩形顶边；矩形顶边在
  标签左侧**直线延伸至侧边栏**（垂直直角，无圆弧）；「凸字形」上边框描线——
  反圆角与矩形顶边均描线，**标签底边与矩形顶边重合段不描线**；非活跃标签 =
  框架底色 + 顶部圆角。
- **边框分层（框架组）**：顶栏 + 左侧边栏 + 软件状态区 = 同一整体（同一底色）；
  软件状态区位于侧边栏底部，额外上边线（**与侧边栏两边对齐**）；内容区 =
  页面底色（`#F6F7F9` 系）**全幅展开，不用圆角矩形包裹**，一体感由活跃标签的
  反圆角衔接实现。

### 4.1 设备页内结构

上部卡片列 + 下部 EQ 曲线（始终可见）。预设 / 高级视图差异：

| 区域 | 预设视图 | 高级视图 |
|---|---|---|
| 卡片列 | 无圆形加号；空态（仅卡片列为空时）居中一行「从预设栏添加调音」，无虚线框 | 出现圆形加号（添加 peaking）；通道选择器开启后顶部出现通道选择栏头 |
| 通道选择器 | 不可用（所有声道一致） | off = 所有声道一致；on = 分栏（入口：侧边栏高级栏） |
| EQ 曲线 | 合成显示（无声道下拉） | 标题旁下拉切换声道，切换栏位曲线自动跟随 |

> **频响曲线标准网格**：Y 轴 `+6 / +3 / 0 / -3 / -6 / -10 / -16` 各一根虚线；
> X 轴对数排布 `20 / 50 / 100 / 200 / 500 / 1k / 2k / 5k / 10k / 20k` 各一根
> 虚线；设备信息仅显示 `{通道数}ch · {采样率}Hz · {位深}bit`（不含设备名）。

### 4.2 通道选择器（channel selector）状态机

- **off（默认）**：所有声道共用同一套调音；块不写 `channels`（应用全部声道）；
  可切换预设视图；**开启入口 = 侧边栏高级栏的「通道选择器」项**（添加即 on）。
- **on**：**标签页与卡片之间的空白处**出现**通道选择栏头**——`左声道 ｜ 右声道`
  采用**下划线分段切换器**（同侧边栏预设 / 自定义样式），加号（枚举设备声道列表，
  勾选添加，声道满后加号隐藏），**最右侧「管理」**（删除 / 增加通道 / 关闭通道
  选择器）；管理**只出现在该栏位最右侧**，组卡内不出现；每块必须显式 `channels`；
  **该设备禁止切回预设视图**（仍可从侧边栏添加预设，仅无语义显示，落入当前激活
  声道列）。
- **off → on**：已有卡片**复制到 L / R**（每声道独立副本），其他声道不应用；
  新增声道从空开始。
- **on → off**：在栏头最右侧「通道管理」中点击**关闭通道选择器**；以当前激活
  声道链为共享链，其余声道独立内容丢弃（操作需确认；细则留 06）。

### 4.3 声道预算

- 每声道 peq 段数**独立 ≤ 31**：块计入其 `channels` 声道的预算；
  off（缺省 channels）时计入每个声道。

## 五、下边栏（并入框架组）

- 原全宽底栏取消：**软件状态**区并入框架组（侧边栏底部，额外上边线）——当前语言、
  浅色 / 深色 / 跟随系统、全局调音开关；是顶栏「设置」面板对应项的快捷入口。
- 右侧**设备信息**并入**频响曲线卡片**标题行（名称 / 格式等）。

## 六、数据契约联动（登记，后续任务）

- **01 `3.1` 修订**：块模型增加 channels 语义——通道选择器 off 时块不写
  `channels`（应用全部声道）；on 时每块必须显式 `channels`。
- **01 `3.2` 修订**：段数约束由“全局合计 ≤ 31”改为“**按声道分组 ≤ 31**”。
- **driver 校验调整（另立任务）**：v9.16 的全局 peq band 合计校验改为按声道分组；
  错误信息形如 `channel 'L' peq bands count N exceeds max 31`。
- 预设视图 = 单链共享（selector off）；高级分栏 = 每声道独立链（selector on）。

## 七、Assumptions（登记，细则待 06 确认）

- 新增声道（加号添加）从空开始，不复制现有卡片；删除声道 = 删除该声道全部块
  （确认后执行）。
- 高级视图下从侧边栏添加预设 / 滤波器 / 效果器，落入**当前激活声道**列。
- 顶栏「设置」= 打开应用设置面板；下边栏状态项是其快捷入口。
- 非 PEQ 效果器（wide 等）参数面板的具体交互留 06 / 07，本文档只定可添加性与
  落入位置。
- on → off 回退以当前激活声道为准，其余差异丢弃（确认后执行）。
