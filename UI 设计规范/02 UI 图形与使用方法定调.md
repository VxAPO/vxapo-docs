## 一、技术栈

- 框架：Tauri + TypeScript + React + Tailwind CSS v4 + shadcn/ui。
- shadcn 落地约定：
  - 先 `npx shadcn@latest init` 建立 `components.json` 与 path alias
    （`@/components/ui`），组件一律经 CLI 安装，不手抄源码；
  - 使用复合组件模式（`Card + CardHeader + CardContent`、
    `Dialog + DialogContent` 等），自定义组件统一 `cn()` / `cva`；
  - 语义化组件（`Button`、`Dialog` 等）自带 ARIA，不手工覆写。
- 令牌来源：`_归档/UI 设计规范 v1（三TAB草案）.md` 的设计令牌已在
  `App.css` 落地（`--surface-*` / `--radius-*` / `--space-*` / `--shadow-*`），
  本文档延续，不另起颜色/字体体系。

## 二、图形语言铁律

**可点的按钮与功能控件 = 胶囊（pill）；承载内容的卡片与容器 = 圆角（rounded）。**

| 元素 | 形状 | 令牌 |
|---|---|---|
| 按钮 / 标签页 / 开关 / 图标按钮 / 下拉触发器 / 段数徽标 | 胶囊 | `--radius-pill`（9999px） |
| 卡片 / 容器 / 弹窗 / 输入框 / 下拉面板 | 圆角 | `--radius-xl`（16px）或 `--radius-2xl`（24px） |
| 滑块轨道 / 手柄（非按钮非卡片） | 中等圆角 | `--radius-md` / `--radius-lg` |

- **嵌套半径**：大组卡片（GroupCard）用 24px，内部小卡（NameCard）用 16px——
  外大内小，层级一眼可辨。
- 胶囊只属于“按一下会触发动作”的控件；把卡片做成胶囊是反模式。
- 滑块本体不胶囊化：轨道/手柄保持常规圆角，避免与按钮混淆。

## 三、布局定调（Bento Grid）

- 页面骨架沿用 01：**上部视图区（预设/高级，可切换）+ 底部固定区（曲线 + 运行参数）**。
- 上部视图区采用 **Bento Box Grid**：
  - 4 列 CSS Grid，`gap: 16px`，单元格支持 1×1 / 2×1 / 2×2 变跨；
  - 预设视图：每个 group 是一张 2×1 起步的大卡，组内 name 小卡横向排列
    （宽度 = 滑块数）；
  - 高级视图：无组 band 用 1×1 密集单元，有组块仍按 GroupCard 呈现；
  - 响应式 4→2→1 列（断点 375 / 768 / 1024 / 1440）。
- 底部固定区：
  - 曲线单元 = 通栏或 2×1 bento 单元，**始终可见**，不随视图切换消失；
  - 运行参数单元 = 右侧 1×1 单元，内容为状态徽标 + 设备信息
    （安装 / 调音 / 保存 / 响度 / 声道 / 采样率 / 位深）。
- 卡片视觉：`surface-card` 背景 + `--shadow-card` 细描边阴影；
  hover 轻微抬升（scale 1.02），切换/增删时平滑布局（150–300ms，
  尊重 `prefers-reduced-motion`）。

## 四、组件词汇表（图形层）

### 胶囊组（可点）

- `TabButton`（预设视图 / 高级视图）、`IconButton`（顶栏工具）、
  `Toggle`（调音 / 响度）、`SaveButton`、`ImportButton`、`ExportButton`、
  `MenuTrigger`（组标签菜单）、`ApplyPresetButton`、`AddBandButton`、
  `BandCountBadge`（段数预算徽标，超限态用 `--danger-red`）。

### 圆角组（承载）

- `BentoCell`（布局基元）、`GroupCard`（大组，24px）、`NameCard`（小组，16px）、
  `BareBandCell`（无组单 band，1×1）、`CurveCell`（频响曲线）、
  `StatusCell`（运行参数）、`ConfirmDialog` / `ImportDialog`（圆角弹窗）。

### 层级与图标

- 背景 `surface-content` → bento 单元格 `surface-card` + `shadow-card` →
  嵌套小卡 `surface-raised` / `surface-sunken`。
- 图标统一 Lucide（SVG），胶囊内 16–18px；**禁止 emoji 充当图标**。

## 五、使用方法定调（Usage）

- **预设视图**：点预设（pill）→ 生成 GroupCard；组内 NameCard 含 N 个
  1:1 语义滑块（标签 = name，序号/频段副标区分）；删除入口 = 组卡头 pill 按钮，
  触发圆角确认弹窗；段数超 31 时应用按钮禁用并展示预算徽标
  （预设段数 / 当前 / 剩余）。
- **高级视图**：`AddBandButton`（pill）新增 BareBandCell；有组块仍为
  GroupCard，滑块显示频率 / Q / gain；编辑数值不拆卡。
- **底部固定区**：状态项 = 胶囊徽标 / 开关；设备信息 = 文本；
  曲线始终可见，band 在曲线上以可拖点呈现（拖拽交互留 03）。
- **保存 / 导入 / 导出**：顶栏 pill 按钮组；导入弹窗（圆角卡）提供
  01 定义的双选项（完整导入 / 仅结构导入，丢弃 fc）。
- **反馈基调**（ui-ux-pro-max UX 通用规则）：hover 有光标与视觉变化、
  active 立即反馈、成功有确认（toast / 状态变化）、错误就近提示、
  删除等破坏性操作必须有确认弹窗。
