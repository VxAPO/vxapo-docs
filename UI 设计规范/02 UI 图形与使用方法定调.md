## 一、技术栈与品牌色

- 框架：Tauri + TypeScript + React + Tailwind CSS v4 + shadcn/ui。
- shadcn 落地约定：
  - 先 `npx shadcn@latest init` 建立 `components.json` 与 path alias
    （`@/components/ui`），组件一律经 CLI 安装，不手抄源码；
  - 使用复合组件模式（`Card + CardHeader + CardContent`、
    `Dialog + DialogContent` 等），自定义组件统一 `cn()` / `cva`；
  - 语义化组件（`Button`、`Dialog` 等）自带 ARIA，不手工覆写。
- 令牌来源：`--radius-*` / `--space-*` / `--shadow-*` 沿用 v1 草案 / `App.css`；
  **主题 = 白 / 黑基底微偏调**（见下），**品牌青只做指引色**，不再沿用 v1 的
  `--accent-green`。
- 字体：**Plus Jakarta Sans**（拉丁 / 数字，本地打包 woff2，不依赖 Google Fonts
  运行时加载）+ `"Microsoft YaHei UI"` 中文回退；替换 v1 的 DM Sans。

### 主题方向（白 / 黑基底，微偏调）

- 浅色主题：以白色为基底（`#FFFFFF` 底色层），表面取微偏调中性色
  （`#F9FAFB`）与品牌浅背景（`#E0F7F7`）；文字近黑（`#0F1115`）。
- 深色主题：以黑色为基底（`#0F1115` 底色层，不用纯黑），表面取微偏调中性色
  （`#17191E`）与品牌深背景（`#081F1F`）；文字近白（`#F8FAFC`）。
- 主题只由黑 / 白基底展开，品牌青不参与主题底色；**深靛蓝方向弃用**。

### 品牌青（指引色）

- **最终定版（logo）**：主色 `#33CCCC`（≈ HSL 180°, 60%, 50%）、深色 `#009AA2`
  （≈ HSL 183°, 100%, 32%）；延申只做权重混合，不另造 logo 色。

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--brand` | `#33CCCC` | 选中态、开关开启、曲线高亮、band 点、主操作提示（指引色） |
| `--brand-deep` | `#009AA2` | 浅色底上的品牌文字 / 图标、按压态、深色视觉锚点 |
| `--brand-soft-bg` | `rgba(51, 204, 204, 0.12)` | 选中卡片 / 开关开启的软背景 |

- 品牌青是**指引色**：只做强调 / 选中 / 高亮与定位，**不主导主题**；
  危险红 `--danger-red` 保留用于删除/超限。
- 对比度基线：浅色底品牌文字用 `--brand-deep` `#009AA2`（≈3.4:1，适合大号 /
  加粗 / 图标）；小号正文若需严格 AA，用文本专用加深延申 `#006F75`
  （非 logo 色，仅文本角色）。

### 主题令牌（品牌色延申定义）

推导规则：**`品牌色 × 权重 + 底色（白 / 黑）`**，角色权重固定，实现时按同一公式
重算。结构对应示例（基底 / 表面 / 品牌浅背景 · 正文 / 品牌文字 / 次要文字 ·
品牌描边 / 中性描边）：

| 角色 | 令牌 | 浅色主题 | 深色主题 |
|---|---|---|---|
| 基底背景 | `--bg-base` | `#FFFFFF` | `#0F1115` |
| 表面背景 | `--bg-surface` | `#F9FAFB` | `#17191E` |
| 品牌浅/深背景 | `--bg-brand-tint` | `#E0F7F7`（品牌 15% + 白） | `#081F1F`（品牌 15% + 黑） |
| 正文 | `--text-primary` | `#0F1115` | `#F8FAFC` |
| 品牌文字 | `--text-brand` | `#009AA2`（≈3.4:1，大号/加粗；小号用 `#006F75`） | `#33CCCC`（≥4.5:1） |
| 次要文字 | `--text-secondary` | `#61666B` | `#9BA1A6` |
| 品牌描边 | `--border-brand` | `#A3E8E8`（品牌 45% + 白） | `#0F3D3D`（品牌 30% + 黑） |
| 中性描边 | `--border-neutral` | `rgba(0,0,0,0.1)` | `rgba(255,255,255,0.1)` |

说明：品牌青只进入 `--text-brand` / `--border-brand` / `--bg-brand-tint` 及
选中与高亮角色，不主导背景层级；浅色主题品牌文字对比度以文档标注为准。

## 二、图形语言铁律

**核心理念：需要用户做出决策 / 触发动作的交互元素 = 胶囊（pill，含圆形加号等
圆形控件）；承载与呈现信息的布局 = 圆角矩形（rounded）。**

| 元素 | 形状 | 令牌 |
|---|---|---|
| 按钮 / 标签页 / 开关 / 图标按钮 / 下拉触发器 / 段数徽标 | 胶囊 | `--radius-pill`（9999px） |
| 卡片 / 容器 / 弹窗 / 输入框 / 下拉面板 | 圆角 | `--radius-xl`（16px）或 `--radius-2xl`（24px） |
| 滑块轨道 / 手柄（非按钮非卡片） | 中等圆角 | `--radius-md` / `--radius-lg` |

- **嵌套半径**：大组卡片（GroupCard）用 24px，内部小卡（NameCard）用 16px——
  外大内小，层级一眼可辨。
- 胶囊是「决策 / 交互」元素（按钮、开关、圆形加号、视图滑块等）；圆角矩形是
  「信息布局」元素（卡片、容器、面板、曲线单元）。把信息容器做成胶囊、或把
  决策按钮做成圆角矩形，都是反模式。
- 滑块本体不胶囊化：轨道/手柄保持常规圆角，避免与按钮混淆。

## 三、布局定调（Bento Grid）

- 页面骨架沿用 01：**上部视图区（预设/高级，可切换）+ 底部固定区（曲线 + 运行参数）**。
- 上部视图区采用 **Bento Box Grid**：
  - 4 列 CSS Grid，`gap: 16px`，单元格支持 1×1 / 2×1 / 2×2 变跨；
  - 预设视图：每个 group 是一张 2×1 起步的大卡，组内 name 小卡横向排列
    （宽度 = 滑块数）；
  - 高级视图：无组 band 用 1×1 密集单元，有组块仍按 GroupCard 呈现；
  - 响应式 4→2→1 列（断点 375 / 768 / 1024 / 1440）。
- 底部固定区：
  - 曲线单元 = 通栏或 2×1 bento 单元，**始终可见**，不随视图切换消失；
  - 运行参数单元 = 右侧 1×1 单元，内容为状态徽标 + 设备信息
    （安装 / 调音 / 保存 / 响度 / 声道 / 采样率 / 位深）。
- 卡片视觉：`surface-card` 背景 + `--shadow-card` 细描边阴影；
  hover 轻微抬升（scale 1.02），切换/增删时平滑布局（150–300ms，
  尊重 `prefers-reduced-motion`）。

## 四、组件词汇表（图形层）

### 胶囊组（可点）

- `TabButton`（预设视图 / 高级视图）、`IconButton`（顶栏工具）、
  `Toggle`（调音 / 响度，开启态 = 品牌青）、`SaveButton`、`ImportButton`、`ExportButton`、
  `MenuTrigger`（组标签菜单）、`ApplyPresetButton`、`AddBandButton`、
  `BandCountBadge`（段数预算徽标，超限态用 `--danger-red`）。

### 圆角组（承载）

- `BentoCell`（布局基元）、`GroupCard`（大组，24px）、`NameCard`（小组，16px）、
  `BareBandCell`（无组单 band，1×1）、`CurveCell`（频响曲线）、
  `StatusCell`（运行参数）、`ConfirmDialog` / `ImportDialog`（圆角弹窗）。

### 层级与图标

- 背景 `surface-content` → bento 单元格 `surface-card` + `shadow-card` →
  嵌套小卡 `surface-raised` / `surface-sunken`。
- 图标统一 Lucide（SVG），胶囊内 16–18px；**禁止 emoji 充当图标**。

## 五、使用方法定调（Usage）

- **预设视图**：点预设（pill）→ 生成 GroupCard；组内 NameCard 含 N 个
  1:1 语义滑块（标签 = name，序号/频段副标区分）；删除入口 = 组卡头 pill 按钮，
  触发圆角确认弹窗；段数超 31 时应用按钮禁用并展示预算徽标
  （预设段数 / 当前 / 剩余）。
- **高级视图**：`AddBandButton`（pill）新增 BareBandCell；有组块仍为
  GroupCard，滑块显示频率 / Q / gain；编辑数值不拆卡。
- **底部固定区**：状态项 = 胶囊徽标 / 开关；设备信息 = 文本；
  曲线始终可见，band 在曲线上以可拖点呈现（拖拽交互留 03）。
- **保存 / 导入 / 导出**：顶栏 pill 按钮组；导入弹窗（圆角卡）提供
  01 定义的双选项（完整导入 / 仅结构导入，丢弃 fc）。
- **反馈基调**（ui-ux-pro-max UX 通用规则）：hover 有光标与视觉变化、
  active 立即反馈、成功有确认（toast / 状态变化）、错误就近提示、
  删除等破坏性操作必须有确认弹窗。

## 六、来源与依据

- ui-ux-pro-max：`Bento Box Grid` / `Bento Grids` 样式模式
  （16–24px 圆角、软阴影、hover scale 1.02、响应式 4→2→1）；
  shadcn 栈指南（CLI 安装、path alias、复合组件）；
  UX 通用规则（hover / active / success / error / destructive-confirm）；
  Plus Jakarta Sans 采纳自设计系统推荐（字体本地打包）。
- 品牌色族：**最终定版 `#33CCCC` / `#009AA2`**（HSL 180–183°，S 60–100）——
  用户定调，作为**指引色**（强调 / 选中 / 高亮，不主导主题）；延申只做权重混合。
- 主题方向：白 / 黑基底微偏调（浅色 `#F5F5F7` 系 / 深色 `#202020` 系，均非纯色）——
  用户定调；深靛蓝方向弃用。
- 主题令牌结构：品牌色延申定义（背景分层 / 文字 / 描边角色，`品牌色 × 权重 + 底色`
  推导）——用户示例结构，见「主题令牌（品牌色延申定义）」。
- 项目既有：v1 中性令牌（归档草案 + App.css）、`01` 数据契约与视图语义。
