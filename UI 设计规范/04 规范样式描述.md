# VxAPO UI 设计规范 — 04 规范样式描述（参数 × 文案）

> 状态：设计定稿（v1，2026-08-13）｜ 对应仓库：docs（模块引用规范）
> 本文档**串联 01 / 02 / 03**：01 定数据与视图语义、02 定图形令牌、03 定布局，
> 本文档为每个 UI 部分给出**规范性样式描述**——参数（形状 / 尺寸 / 间距 / 颜色 /
> 字体 / 状态）与**文案**（标签 / 空态 / 提示 / 确认）结合，非纯代码。
> 交互细则归 `05`；本文件不写交互。

## 一、顶栏

## 二、左侧边栏

> 串联：03 三（「效果」标题 + 下划线分段切换器）｜ 02（卡片 = 圆角信息布局）

**参数**

| 项 | 参数 |
|---|---|
| 侧边栏宽度 | 260px，背景 `--surface-content` |
| 栏头 | **下划线分段切换器**：一行灰字（预设｜自定义｜高级），选中字变黑、下方灰条对应段变黑，点击左右滑动（150–300ms） |
| 预设/自定义卡片 | 圆角 16px（`--radius-xl`），内边距 12–16px，图标区 40px，卡片间距 12px |
| 自定义卡右上角关闭 | 20px 胶囊图标按钮，hover `--danger-red-soft` |
| 高级列表项 | 高 32px，行内间距 8px，hover `--surface-raised` |
| 圆形加号 | 24px 圆形，底色 `--brand-soft-bg`，加号 `--brand`，hover 加深 |
| 未实现项（滤波器占位） | 置灰 `--text-disabled`，不可点 |

**文案**

| 场景 | 文案 |
|---|---|
| 栏头 | 「预设」「自定义」「高级」 |
| 预设卡片 | 预设名（主）＋ 简介（次，两行省略） |
| 添加按钮 tooltip | 「添加到当前设备」 |

| 高级分类 | 「滤波器」「效果器」「通道选择器」「通道」 |
| 滤波器子项 | 「Peak」（可用）；「高架」「低架」「低通」「高通」（置灰，tooltip「未实现」） |
| 效果器子项 | 「Wide」「Aural」「Reverb」「Maximizer」「Loudness」 |
| 通道选择器项 tooltip | 「开启后按声道分栏调音」 |

## 三、内容块（设备标签页体系）

> 串联：03 四（标签页 + 安装页）｜ 02（标签页 = 决策元素 → 胶囊）

**参数**

| 项 | 参数 |
|---|---|
| 标签栏 | 高 36px，背景 `--surface-tab` |
| 设备标签页 | **反圆角标签页**（活跃：`clip-path: shape(...)`，背景 = 页面底色，与内容页同色一体；最左侧反圆角转直线垂直左边框、圆角 6px、整边 1px 描线；非活跃：框架底色 + 顶部圆角） |
| 边框分层 | 顶栏 + 侧边栏 + 软件状态区同一底色（框架组）；内容区全幅页面底色（`#F6F7F9` 系），**不用圆角矩形包裹**；一体感由活跃标签反圆角衔接实现 |
| 标签页左标记（调音开关） | 20px 胶囊开关，开启 `--brand`，关闭 `--border-strong` |
| 标签页右标记（卸载） | 20px 胶囊图标，hover `--danger-red-soft` |
| `+` 按钮 | 28px 胶囊，hover `--surface-raised` |
| 安装页 | 圆角 16px 卡片容器（信息布局），列表行高 40px，进度条高 4px（`--brand`） |

**文案**

| 场景 | 文案 |
|---|---|
| 新设备安装页标题 | 「新设备安装」 |
| 设备类型分组 | 「播放设备」「捕获设备」 |
| 安装/卸载操作 | 勾选 = 安装，取消勾选 = 卸载 |
| 进度 | 「正在安装…」「正在卸载…」「已安装」「安装失败：{原因}」 |
| 卸载确认 | 「确定卸载设备「{设备名}」？该设备的调音配置将被移除。」按钮：「取消」「卸载」 |

## 四、设备页内：卡片列

> 串联：01（group/name/band 语义）｜ 02（嵌套半径 24/16）｜ 03（预设/高级差异）

**参数**

| 项 | 参数 |
|---|---|
| GroupCard | 圆角 24px（`--radius-2xl`），背景 `--bg-card` + 1px 描边，内边距 14px；**宽度 = fit-content**（随子卡总宽收缩，不占满整行）；右上角 X 删除 |
| NameCard | 圆角 16px（`--radius-xl`），宽 96px（单 name = 单段），竖排：name（强）→ 副标（弱）→ 竖滑块 |
| 竖排滑块（fader） | 轨道 6px、高 110px，手柄 18px 圆形（品牌青），值 11px 品牌深色 |
| 顺序标号 | 组 `01`、name/band `01.1`…，高对比胶囊徽标（`--accent-bg` / `--on-accent`），拖拽重排（交互归 05） |
| 卡片级开关 | 胶囊开关，开启 `--brand` |
| 子卡删除 | name / band 卡右上角 20px 胶囊 X（hover 危险色） |
| 高级视图圆形加号 | 24px 圆形（同侧边栏规格） |
| 通道选择栏头 | 高 36px；声道切换 = **下划线分段切换器**（同侧边栏预设/自定义样式）；加号 24px 圆形；最右「管理」；仅 selector on 显示（标签页与卡片之间），组卡内不出现管理 |
| peak 卡（高级） | 宽 168px，自上而下：Fc 输入 → Q 输入 → Gain 滑块 → Gain 数值；输入框圆角 8px |
| 预设视图空态 | **仅卡片列为空时显示**：居中一行 12px 次色文字，无虚线框、无底色 |

**文案**

| 场景 | 文案 |
|---|---|
| 预设视图空态文案 | 「从预设栏添加调音」（仅卡片列为空时显示） |
| 通道选择栏头声道 | 「左声道」「右声道」＋ 已添加声道名 |
| 通道管理按钮 | 「管理」 |
| 管理菜单内关闭项 | 「关闭通道选择器」（危险色，确认后执行） |
| 通道满态 tooltip | 「声道已满」 |
| 空态（高级无 band） | 「点击圆形加号添加 peaking」 |

## 五、EQ 曲线单元

> 串联：03 4.1（曲线始终可见 + 声道下拉）｜ 02（品牌青指引色）

**参数**

| 项 | 参数 |
|---|---|
| 单元高度 | 200–240px，背景 `--bg-surface`，描边 `--border-neutral` |
| 网格线（Y） | `+6 / +3 / 0 / -3 / -6 / -10 / -16`，各一根虚线 |
| 网格线（X） | 对数排布 `20 / 50 / 100 / 200 / 500 / 1k / 2k / 5k / 10k / 20k`，各一根虚线 |
| 曲线 | 2px `--brand`（指引色） |
| band 点 | 10px 圆形，`--brand`；选中态 14px + `--ring`（`--brand` 柔化） |
| 标题行 | 高 32px；声道下拉 = 胶囊（决策元素） |
| 设备信息 | 标题行右侧：`{通道数}ch · {采样率}Hz · {位深}bit`（**不含设备名**） |
| 空态 | 居中 12px 次色文字 |

**文案**

| 场景 | 文案 |
|---|---|
| 单元标题 | 「频响曲线」 |
| 高级视图声道下拉 | 「声道：左声道」「声道：右声道」… |
| 空态 | 「无启用段，从侧边栏或卡片列添加」 |
| 刻度提示 | dB 数值 tooltip「{freq} Hz · {gain} dB · Q {q}」 |

## 七、通用组件（弹窗 / 确认 / toast）

> 串联：02（决策 = 胶囊，信息 = 圆角矩形）｜ 03（确认场景：卸载、删除、关闭通道选择器）

**参数**

| 项 | 参数 |
|---|---|
| Dialog | 圆角 16px，最大宽 420px，内边距 20px，蒙层 `--surface-overlay` |
| 确认按钮 | 胶囊；危险操作（卸载/删除/关闭选择器）用 `--danger-red` |
| Toast | 圆角 12px，`--surface-sunken` + `--shadow-md`，成功标记 `--brand` |
| 错误提示 | 就近文字，`--danger-red` |

**文案模板**

- 确认删除：`确定删除「{名称}」？此操作不可撤销。`（按钮：取消 / 删除）
- 确认卸载：见第三节卸载文案。
- 确认关闭通道选择器：`关闭后将按当前声道合并调音，其余声道内容将被丢弃。`（按钮：取消 / 关闭）
- 成功 toast：`已保存` / `已应用` / `已导入 N 个预设`
- 失败提示：`{操作}失败：{原因}`

## 八、来源与约束

- 每个部分的「参数 / 文案」均为规范值；实现时以本文件为准，令牌引用 02，布局引用 03，
  数据语义引用 01。
- 颜色克制遵循 02：品牌青仅作点缀，主视觉为强对比黑白，避免弱对比灰混品牌色。
- 本文件不写交互（拖拽、菜单触发、确认流程的动线归 `05 交互细则`）。
