# VxAPO UI 设计规范 — 04 规范样式描述（参数 × 文案）

> 状态：设计定稿（v1，2026-08-13）｜ 对应仓库：docs（模块引用规范）
> 本文档**串联 01 / 02 / 03**：01 定数据与视图语义、02 定图形令牌、03 定布局，
> 本文档为每个 UI 部分给出**规范性样式描述**——参数（形状 / 尺寸 / 间距 / 颜色 /
> 字体 / 状态）与**文案**（标签 / 空态 / 提示 / 确认）结合，非纯代码。
> 交互细则归 `05`；本文件不写交互。

---

## 一、顶栏

> 串联：03 二（顶栏 9 项）｜ 02（胶囊 = 决策元素）

**参数**

| 项 | 参数 |
|---|---|
| 顶栏高度 | 48px，背景 `--surface-frame`，描边 `--border-neutral` |
| 工具按钮（设置/保存/导入/导出） | 胶囊，高 28–32px，内边距 10–14px，间距 8px |
| 视图切换滑块 | 胶囊轨道（2 段），选中段填充 `--brand-soft-bg` + `--brand` 文字 |
| 窗口控件（最小化/最大化/关闭） | 36×28px 胶囊，hover `--surface-raised`，关闭 hover `--danger-red-soft` |
| 保存未保存态 | 保存按钮显示未保存圆点（`--brand`），已保存隐藏 |

**文案**

| 场景 | 文案 |
|---|---|
| 工具按钮 tooltip | 「设置」「保存」「导入」「导出」 |
| 保存成功 | toast「已保存」 |
| 导入弹窗标题 | 「导入配置」 |
| 导入选项 | 「完整导入」「仅导入结构（不含频率）」 |
| 视图切换 | 「预设」「高级」 |

| NameCard | 圆角 16px（`--radius-xl`），背景 `--surface-raised`，宽度 = 滑块数 × 28px |

| 项 | 参数 |
|---|---|

| 场景 | 文案 |

| 空态 | 「无启用段，从侧边栏或卡片列添加」 |
| 刻度提示 | dB 数值 tooltip「{freq} Hz · {gain} dB · Q {q}」 |

## 七、通用组件（弹窗 / 确认 / toast）

> 串联：02（决策 = 胶囊，信息 = 圆角矩形）｜ 03（确认场景：卸载、删除、关闭通道选择器）

**参数**

| 项 | 参数 |
|---|---|
| Dialog | 圆角 16px，最大宽 420px，内边距 20px，蒙层 `--surface-overlay` |
| 确认按钮 | 胶囊；危险操作（卸载/删除/关闭选择器）用 `--danger-red` |
| Toast | 圆角 12px，`--surface-sunken` + `--shadow-md`，成功标记 `--brand` |
| 错误提示 | 就近文字，`--danger-red` |

**文案模板**

- 确认删除：`确定删除「{名称}」？此操作不可撤销。`（按钮：取消 / 删除）
- 确认卸载：见第三节卸载文案。
- 确认关闭通道选择器：`关闭后将按当前声道合并调音，其余声道内容将被丢弃。`（按钮：取消 / 关闭）
- 成功 toast：`已保存` / `已应用` / `已导入 N 个预设`
- 失败提示：`{操作}失败：{原因}`
