# VxAPO Driver 代码审查摘要

本文档汇总历史代码审查中的关键结论，避免保留大量独立审查文件。详细实现以当前代码为准。

## 主要结论

### `sys/`

- COM 接口与 IID 集中管理，避免重复定义。
- 注册表访问使用最小权限 SAM，适配 MMDevices ACL。
- GUID 格式化统一走 `sys/com/prelude::guid_to_string`。

### `pipeline/`

- `Chain` 不持有缓冲区，缓冲由对象层预分配。
- 实时路径禁止堆分配、锁和 I/O。
- DSP 数值安全采用解析层 clamp、系数层 f64、RT 层 FTZ/DAZ 三层防线。
- PEQ 使用 200 Hz 分频混合架构。
- 延迟不上报，避免帧协商错位。

### `install/`

- 设备枚举唯一入口为 `enumerate_devices`。
- 安装/卸载使用事务保护，失败自动回滚。
- 只卸载 VxAPO 自有部分，不触碰其他 APO。
- `select.rs` 已删除，交互选择由 CLI/App 承担。

### `config/`

- 旧 `config.txt` 命令体系已移除，统一为 TOML 模型。
- `FileModel -> ChainModel` 转换在 config 层完成。
- spec 指纹只包含 DSP 字段。

### `object/`

- `ApoObject` 是多模块胶水层，负责 COM 生命周期与配置热重载。
- 子 APO 通过 `HKLM\SOFTWARE\VxAPO\Child APOs` 管理。
- DLL 注册必须补写 `AudioEngine\AudioProcessingObjects` 键。

### `telemetry/` 与 `utils/`

- 日志使用无锁环形缓冲，RT 安全。
- 错误类型统一为 `VxApoError`。
- GUID 解析与格式化职责分离。
