# VxAPO Driver 文档

本目录面向 `vxapo-driver`（Windows APO DLL）的架构、模块规范、配置/DSP 设计与安装排障。

## 文档导航

| 文件 | 内容 |
|------|------|
| `架构与模块规范.md` | 模块树、依赖规则、数据流、线程安全模型、关键设计决策 |
| `配置与DSP设计.md` | config.toml 模型、效果器类型、PEQ 混合架构、DSP 数值安全 |
| `安装与排障.md` | 安装/卸载流程、槽位与子 APO、快照、audiodg 不加载根因与排查 |
| `代码审查摘要.md` | 历史代码审查结论汇总 |
| `模块引用规范/` | 详细模块引用规范（开发指南，按模块拆分） |

> 详细代码以 `VxAPO/vxapo-driver/src` 为准；本文档是对现有实现的整理与规范说明。
