# VxAPO 项目概览

## 1. 项目定位

VxAPO 是一个 Windows 音频 APO（Audio Processing Object）DSP 引擎，提供：

- 实时音频 DSP 处理：EQ、增益、响度、混响、动态压缩、声场加宽等。
- 设备级配置管理：每个音频端点一份 `config.toml`。
- 面向不同层级用户的界面：CLI 与 GUI App。
- 热重载与双链过渡：修改配置时无爆音、无中断。

## 2. 系统组成

| 组件 | 说明 |
|------|------|
| `vxapo-driver` | Windows APO DLL，核心 DSP 与安装逻辑 |
| `vxapo-cli` | 命令行工具，设备枚举、安装/卸载、配置、快照 |
| `vxapo-app` | Tauri 2 + React 桌面应用，面向终端用户的图形界面 |

## 3. 当前架构

```text
vxapo-app (React/Tauri)
    |
    | config.toml / CLI --json
    v
vxapo-cli --------------------> vxapo-driver (install layer)
    |
    | config.toml
    v
Windows audiodg.exe
    |
    v
vxapo_driver.dll (APO)
    -> config parser -> Filter chain -> real-time DSP
```

## 5. 当前状态

- driver 已完成 TOML 配置模型、混合 PEQ、DSP 数值安全、安装/卸载、热重载；
  效果器为 peq/preamp/aural/reverb/compressor/wide/loudness，并含旧 GUID 残留检测、
  迁移与清理（以设备实例 ID 为稳定身份）。
- CLI 已实现 `list/status`、`install`（含 `--verify`）、`uninstall`、`config`、`snapshot`、
  `stale list/migrate/cleanup/fix-acl`。
- App 已实现设备列表、config 读写、自动保存、安装/卸载、导入导出、中英文界面，
  以及旧 GUID 残留横幅（迁移/清理 + ACL 自修复）。
- 生产构建要求：`panic = "abort"`、`codegen-units = 1`。

## 6. 关键设计原则

- 音频是实时的：RT 路径零分配、零锁、零 I/O。
- 配置是设备级的：每个端点独立。
- 改配置不打断声音：热重载 + 升余弦过渡。
- 分层清晰：driver 不依赖 UI，App/CLI 通过文件系统和 CLI 与 driver 交互。
